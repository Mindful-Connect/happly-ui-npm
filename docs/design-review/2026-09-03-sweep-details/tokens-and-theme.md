## Decisions for Ari (surfaced, not changed)
1. **Status fills with white labels** fail WCAG AA 4.5:1 (error 3.66, warning 2.79, success 2.36); they pass the 3:1 UI-component bar. Keep the AlignUI values, or move filled status buttons to the `-600` (warning/error) and `-700` (success) steps.
2. **Soft text** (`text-soft-400`, 2.63:1) is used for placeholders and captions. Keep, or repoint `--color-text-soft-400` to `slate-500` (4.49:1).
3. **Dark-mode accent**: fixed to purple-500 + white label (4.79:1). The alternative that mirrors the previous "light fill, dark label" pattern is purple-400 + `slate-950` label (5.18:1, but 3.62:1 if a consumer keeps a white label).
4. **Input text at 14px** triggers iOS Safari zoom on focus; the two fixes (16px on mobile, or `transform: scale()`) change either the look or the code — needs a call.

## Considered but rejected
| Location | Candidate | Rejected because |
| --- | --- | --- |
| `tokens.ts` raw palette (`colors.gray/slate/blue…`) | convert the V3 plugin palette to oklch too | Tailwind v3 cannot derive `bg-blue-500/50` opacity modifiers from an `oklch()` string; V3 consumers would silently lose `/opacity`. V3 keeps hex in the plugin only. |
| `happly-theme.css` ramps | regenerate the 11 ramps with equal step lightness and matched chroma % | Changes every rendered color in the product; palette-structure.md says an inventory stays a proposal until accepted. Reported instead. |
| `--color-bg-weak-25` | delete the duplicate token | It diverges in dark mode (`neutral-900` vs `-800`) and is public API for installed components. |
| `body {}` | `text-wrap: balance` on all headings | Too global for a token file consumed by arbitrary apps; applied per component instead. |

## Verification
- `node audit.cjs` (culori + apca-w3): ramp audit, 33 contrast pairs, 16 focus-ring candidates over both grounds — tables above.
- `node convert.cjs` on both theme files: 445 + 182 literals converted; `grep -c '#[0-9a-f]{3,8}|rgba?('` → 0 in both files.
- `bunx @tailwindcss/cli -i packages/registry/storybook.css` and `-i tailwind-manual-installation/v4/happly-theme.css`: both compile; output contains 441 `oklch(` declarations and the new `.focus-visible\:shadow-button-primary-focus` rule.
- `bun run build:registry` (registry index, tailwind plugin, theme templates) → clean; `bun run scripts/sync-theme-templates.ts` re-run → all three targets "unchanged" (idempotent).
- `bun x tsc --noEmit` (root) and `bun run --cwd packages/cli typecheck` → pass; `bun run --cwd packages/cli build` → 9.59 MB bundle.
- Not verified: rendered dark-mode screenshots of every component (Storybook has no dark toggle wired); a V3 consumer project build.

## Verdict
Approve for the token layer (no HIGH remains). Two MEDIUM contrast/palette findings are reported as decisions.
