# Second pass

## What the first pass missed

The first pass read class strings and stopped at the element each class sat on. Everything new this
round is one step further out — **what the markup does at runtime** — and it falls into four
repeating shapes, not four one-off bugs:

1. **States that only exist while a prop is set were never rendered.** `Button`'s `loading` state
   swaps the entire label for an animated one. Nobody walked it, so a loading button had no usable
   accessible name (the spinner's label, the incoming letters and the outgoing label all concatenated)
